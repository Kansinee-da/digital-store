Mini Project · UI Design

ร้านขาย Digital Product
ดีไซน์ขาวล้วน เรียบง่าย

ออกแบบ UI 3 แพลตฟอร์ม: Web App · Mobile App · Desktop App ให้ใช้ภาษาดีไซน์เดียวกัน

แนวคิดการออกแบบ (Concept)

"ให้สินค้าเป็นพระเอก ส่วน UI หายไปให้มากที่สุด"

1. ขาวล้วน (Pure White)พื้นหลังขาว ใช้เส้นบางสีเทาอ่อนแบ่งส่วน แทนเงาหนักและสีสัน
2. สีเน้นสีเดียวใช้สีดำเป็นปุ่มหลักเท่านั้น ทำให้ปุ่มซื้อเด่นชัดโดยไม่ต้องใช้สีอื่น
3. ช่องว่างเยอะเว้นระยะกว้าง อ่านง่าย สแกนสินค้าได้เร็ว ลดความรก
4. ประสบการณ์เดียวกันโครงสร้าง ปุ่ม และไอคอนเหมือนกันทุกอุปกรณ์ แค่ปรับเลย์เอาต์ตามหน้าจอ
